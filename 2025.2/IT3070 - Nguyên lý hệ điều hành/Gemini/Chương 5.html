Quản Lý Hệ Thống File (Chương 5)

Kiến trúc lưu trữ, Cấu trúc FAT & Phân tích kỹ thuật byte

Kiến Trúc Đĩa & Hệ Thống Tệp

1. Cấu trúc vật lý đĩa

  • Sector: Đơn vị lưu trữ vật lý nhỏ nhất. Kích thước chuẩn luôn là 512 Bytes.
  • Cylinder: Tập hợp các rãnh (Track) cùng bán kính trên toàn bộ các mặt đĩa.
  • Địa chỉ CHS: Cylinder (10 bit), Head (8 bit), Sector (6 bit).
  • Công thức Sector/Cylinder = Số mặt đĩa (Head) × Số sector trên một rãnh.

2. Master Boot Record (MBR)

  • Nằm tại sector đầu tiên của ổ đĩa vật lý (LBA 0).
  • Chữ ký khởi động (Boot Signature): 2 byte cuối cùng (byte 510 và 511) luôn có giá trị Hex là 55AA.
  • Bảng phân chương (Partition Table): Bắt đầu từ offset 1BEh. Dài 64 Bytes, chia làm 4 phần tử (mỗi phần tử 16 Bytes). 4 byte cuối của mỗi phần tử lưu tổng số sector của phân vùng đó.

3. Hệ thống FAT (File Allocation Table)

  • Sử dụng phương pháp cấp phát Danh sách liên kết (Linked List) (loại bỏ phân mảnh ngoài).
  • Mỗi phần tử (Entry) trong bảng FAT tương ứng với 1 Cluster (bắt đầu từ phần tử thứ 2).
  • Vùng hệ thống:
    FAT16: MBR, Boot Sector, FAT1, FAT2, ROOT.
    FAT32: MBR, Boot Sector, FAT1, FAT2 (ROOT được đẩy vào vùng Data).
  • Giá trị FAT quan trọng: FAT16 kết thúc file (EOF) là FFFF. FAT32 EOF là 0FFFFFFF, đánh dấu Cluster hỏng (Bad) là 0FFFFFF7. FAT32 dùng 4 byte (32 bits) quản lý kích thước file, nên giới hạn kích thước tối đa của một file là 4GB.

4. Phân phối không gian lưu trữ

Phương pháp Đặc điểm Phân mảnh ngoài
Liên tục (Continuous) Truy xuất nhanh, phải dịch chuyển khối liền kề. Có
Liên kết (Linked List) Khối rải rác, truy xuất tuần tự, dễ mất dữ liệu nếu hỏng con trỏ. (FAT dùng cách này) Không
Chỉ mục (Indexed) Mỗi file có Index block riêng, dễ truy xuất trực tiếp (Random Access). Không

Lưu ý: Mọi phương pháp đều gặp hiện tượng Phân mảnh trong (Internal Fragmentation). Lệnh Open File giúp nạp thông tin lên bộ nhớ, tránh phải duyệt đĩa (duyệt cây thư mục) nhiều lần ở các thao tác Read/Write tiếp theo.

Kỹ Thuật Giải Mã Directory Entry (Phần tử ROOT 32-Byte)

Bắt buộc áp dụng quy tắc Little-Endian: Byte có địa chỉ thấp (nằm trước trong chuỗi Hex) đại diện cho các bit thấp. Khi đọc giá trị từ chuỗi Hex, phải đảo ngược thứ tự các byte.

Chuỗi mẫu: 52 45 41 44 4D 42 52 20 43 20 20 20 00 3C 86 5B
           A5 3E A5 3E 00 00 CF 79 A5 3E 40 2E BD 0A 00 00

1. Đọc tên File (11 Byte đầu)

  • 8 byte đầu là Tên: `52 45 41 44 4D 42 52 20` -> Tra mã ASCII: READMBR.
  • 3 byte tiếp là Phần mở rộng: `43 20 20` -> ASCII: C. File tên là READMBR.C.

2. Thuộc tính (Byte 11 - Offset 0x0B)

  • 0x01 (Read-Only), 0x02 (Hidden), 0x04 (System), 0x10 (Directory).
  • Kỹ thuật C/C++ kiểm tra: R & 0x02 (nếu khác 0 -> file có thuộc tính Ẩn).

3. Thời gian tạo / Cập nhật (16 bits)

  • Offset Time: Tạo (14h-15h), Cập nhật (16h-17h). Trích xuất 2 byte, ví dụ: CF 79 -> Đảo Little Endian thành 79CF.
  • Đổi 79CF sang nhị phân: 01111 001110 11111.
  • Giờ (5 bit đầu): 01111 = 15h.
  • Phút (6 bit giữa): 001110 = 14m.
  • Giây (5 bit cuối): 11111 = 31 (nhân đôi = 62s. Trong bài thi có câu lấy lỗi chập bit thành 30s).

4. Ngày tháng tạo / Cập nhật (16 bits)

  • Offset Date: Cập nhật (18h-19h). Ví dụ: A5 3E -> Đảo thành 3EA5.
  • Đổi 3EA5 sang nhị phân: 0011111 0101 00101.
  • Năm (7 bit đầu): 0011111 = 31 -> (1980 + 31) = 2011.
  • Tháng (4 bit giữa): 0101 = 5.
  • Ngày (5 bit cuối): 00101 = 5. -> 05/05/2011.

5. Khối Cluster bắt đầu (2 Bytes)

  • Offset 1Ah-1Bh (Byte 26-27). Ví dụ: 40 2E -> Đảo thành 2E40 (Hex).
  • Chuyển sang thập phân: 2*(16^3) + 14*(16^2) + 4*(16^1) + 0 = 11840.

6. Kích thước File (4 Bytes)

  • 4 byte cuối cùng (Offset 1Ch - 1Fh). Ví dụ: BD 0A 00 00 -> Đảo thành 00000ABD.
  • Chuyển sang thập phân: 10*(16^2) + 11*(16^1) + 13 = 2560 + 176 + 13 = 2749 Bytes.
