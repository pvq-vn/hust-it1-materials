Problem Description

The result of an exam of a contest is represented by the sequence of integers a[1], a[2], . . ., a[n] in which a[i] is the point of the participant i (i = 1, . . ., n).

Given a threshold D (which is a positive integer), a participant i is considered to be failed if the result a[i] is smaller than D. Count the number of failed participants.

Input

  • Line 1: contains 2 positive integers n and D (1 <= n, D <= 1000)
  • Line 2: contains a[1], a[2], . . ., a[n] (0 <= a[i] <= 1000)

Output

  • Write the number of failed participants

Example

Input

5 4

3 2 0 8 4

Output

3
