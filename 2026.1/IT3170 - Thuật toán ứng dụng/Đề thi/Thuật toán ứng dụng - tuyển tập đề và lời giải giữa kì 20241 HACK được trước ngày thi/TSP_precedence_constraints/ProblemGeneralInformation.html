Problem Description

Given n points 1, 2, …, n in which d(i,j) is the distance from point i to point j, We need to create a tour starting from one point, then visiting all the remaining points and terminating at the starting point. Let P be the set containing precedence pairs of points (x_i, y_i) such that point x_i must be visited before point y_i in the tour (x_i, y_i in {1, ..., n}).

Find the shortest closed tour so that the total travel distance is minimal.

Input:

  • Line 1: n, the number of points
  • Line i+1 (i = 1, ..., n): the distance values from point i to point j (j = 1, ..., n)
  • Line n+2: |P|, the number of precedence pairs
  • Line n+2+i (i = 1, ..., |P|): the pair (x_i, y_i)

Output:

  • Line 1: the number of points in the best solution
  • Line 2: the sequence of points in the best solution

Example:

Input:

5

0 1 2 3 4

3 0 2 4 5

1 3 0 4 2

4 2 1 0 3

2 3 4 1 0

2

2 4

2 1

Output:

5

2 3 1 5 4
