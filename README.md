## 📌 Định dạng được đồng bộ
Repository chỉ lưu trữ các tệp mã nguồn và dữ liệu nhẹ:
- .ipynb: Jupyter Notebook (Báo cáo, Đề thi, Quiz)
- .py: Python scripts
- .jsx: React / Web components
- .html: Báo cáo, mô phỏng thuật toán trực quan
- .json: Đề thi và dữ liệu cấu trúc
